# Datos de entrada

Los Excel con operaciones del banco **no se suben al repositorio** (ver `.gitignore`). Copiarlos aquí:

| Archivo | Script | Columnas que se usan |
|---|---|---|
| `Registros Stock Construccion.xlsx` | fogaes | `FEC_INF_MES`, `FEC_VEN_FIN`, `CRD_TIP_MON`, `SDO_GTA_MON_PES`, `FRECUENCIA DE PAGO` |
| `Solicitudes Vivienda vigentes.xlsx` | fogaes | `CTL_CSU_IDE_GAV`, `SOL_CRD_MNT_GAR_UF` |
| Stock FOGAPE (ej. `Stock Abril 2024 - GFOK MACA - para Tecno Riesgo.xlsx`) | fogape | mismas columnas que el stock de construcción |

Códigos de moneda (`CRD_TIP_MON`): 999 = CLP, 998 = UF, 13 = USD.
